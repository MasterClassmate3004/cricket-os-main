# Formula 1 OS Prototype

A web-based operating system interface with a personalised Formula One theme.

## Features

1. Constructor's Team Themes: Choose your favorite F1 team on startup, and the entire OS interface will adapt to the chosen constructor's team.
2. Live Telemetry & Timing: Experience a realistic Live Timing leaderboard featuring the 2026 F1 driver lineup so you know who you are driving against!!
3. Live Machine Temperature: Just like an F1 car, your taskbar displays the live machine temps, warning you visually if the engine gets too hot.
4. Pitstop & Reboot for OS: Clicking "Go for a Pitstop" triggers a OS reboot that ensures that you are back with optimal tires in the circuit.
5. Apple-Style Boot Screen: Experience a beautiful loading sequence complete with a synthetic F-Major 9 startup chime when you ignite your workspace!
6. F1 ECU Calculator: A carbon fiber math panel with mechanical clicking keys, featuring an easter egg driver profile pop-up when entering 2026 driver numbers!
7. F1 Wiki Info Browser: A custom web browser with back/forward history navigation and fuzzy autocomplete search for all 11 teams and 22 active drivers!
8. ECU Settings (Steering Wheel Dials): Fine-tune your car using MGU-K, Engine Mapping, Brake Balance (BBAL), Diff entry/mid sliders, tyre compound presets, and DRS wing flaps, complete with a glowing 15-LED rev light bar!
9. Draggable App Shortcuts: Drag, drop, and rearrange your desktop icons freely to customize your high-performance workspace layout!

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Tech Stack

- React 18 (Vite)
- Vanilla CSS
