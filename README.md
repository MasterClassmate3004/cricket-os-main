# Formula 1 OS Prototype

a custom web-based OS themed around Formula 1.

## Features

1. Team Themes: Choose a constructor on startup, and the desktop theme (colors, wallpaper, watermark) updates to match.
2. Live Timing: Telemetry leaderboard with 2026 grids showing real-time driver standings.
3. CPU Temp Monitor: Temperature display in the taskbar that lights up red if it gets too hot.
4. Reboot / Pitstop: Click "Go for a Pitstop" to restart the workspace and clear layout states.
5. Startup Screen: Quick boot sequence animation with F-Major 9 startup chimes.
6. F1 Calculator: Custom carbon fiber keyboard with engine click sounds and driver biography card easter eggs when entering car numbers (like 1, 44, 16, etc).
7. F1 Wiki Search: Mock browser with history tracking and autocomplete to search F1 team stats and active driver profiles.
8. ECU settings: Interactive steering wheel control panel simulating tyre compound choices, diff lock ratios, engine strat mapping, BBAL dials, and a flashing 15-LED rev light bar.
9. Draggable Icons: Drag and reposition desktop icons anywhere on the wallpaper grid.

## Running Locally

To run locally:

1. Clone the repo
2. Run:
   ```bash
   npm install
   ```
3. Run:
   ```bash
   npm run dev
   ```
